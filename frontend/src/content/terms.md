# Termos de Uso e Política de Privacidade — MyBookList

**Última atualização:** Junho de 2026

Bem-vindo ao MyBookList. Antes de criar sua conta, leia atentamente estes Termos de Uso e Política de Privacidade. Ao clicar em "Aceitar", você concorda com todos os termos descritos abaixo.

## 1. Sobre o serviço

O MyBookList é uma aplicação web destinada ao acompanhamento da jornada pessoal de leitura, permitindo aos usuários registrar livros, sessões de leitura, anotações privadas, resenhas públicas e metas de leitura. O serviço é oferecido gratuitamente e está em desenvolvimento contínuo no contexto de um projeto acadêmico.

## 2. Cadastro e responsabilidades do usuário

Para utilizar o MyBookList, o usuário deve criar uma conta fornecendo nome, e-mail e senha. O usuário é responsável por:

- Fornecer informações verdadeiras e atualizadas
- Manter a confidencialidade de sua senha
- Notificar imediatamente qualquer uso não autorizado da conta
- Utilizar o serviço em conformidade com a legislação brasileira

O usuário deve ter no mínimo 13 anos de idade para criar uma conta. Menores de 18 anos devem ter consentimento dos pais ou responsáveis legais.

## 3. Conteúdo gerado pelo usuário

O usuário concede ao MyBookList licença não-exclusiva, mundial e gratuita para armazenar, exibir e processar o conteúdo que cria na plataforma (resenhas, anotações, metas), exclusivamente para o funcionamento do serviço.

Anotações privadas são visíveis apenas ao próprio usuário. Resenhas e demais conteúdos marcados como públicos podem ser exibidos a outros usuários.

É proibido publicar conteúdo que:

- Viole direitos autorais ou de propriedade intelectual de terceiros
- Contenha discurso de ódio, ameaças, difamação ou incitação à violência
- Promova atividades ilegais
- Contenha material sexualmente explícito ou inadequado para menores
- Constitua spam ou propaganda não autorizada

O MyBookList reserva-se o direito de remover qualquer conteúdo que viole estes termos, sem aviso prévio.

## 4. Dados pessoais e privacidade (LGPD)

O tratamento de dados pessoais segue a Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018 — LGPD).

**Dados coletados:**

- Nome, e-mail e senha (com hash criptográfico bcrypt)
- Data de cadastro e de último acesso
- Histórico de livros, sessões de leitura, anotações, resenhas e metas criados pelo usuário
- Dados técnicos de acesso (endereço IP, identificador de sessão)
- Respostas a perguntas de segurança para recuperação de conta (com hash criptográfico)

**Finalidade do tratamento:**

- Autenticação e manutenção da sessão do usuário
- Funcionamento das funcionalidades do serviço
- Recuperação de acesso à conta em caso de senha esquecida
- Análise de uso agregado para melhoria do produto
- Cumprimento de obrigações legais

**Compartilhamento:**

O MyBookList não vende dados pessoais. Dados podem ser compartilhados com:

- A API do Google Books, exclusivamente para busca de informações de obras literárias (nenhum dado pessoal do usuário é enviado a esta API)
- Autoridades competentes, mediante ordem judicial

**Direitos do titular:**

Conforme a LGPD, o usuário tem direito a:

- Confirmar a existência de tratamento de seus dados
- Acessar seus dados
- Corrigir dados incompletos, inexatos ou desatualizados
- Solicitar exclusão definitiva de sua conta e dados pessoais
- Solicitar portabilidade de dados
- Revogar o consentimento

A exclusão da conta pode ser solicitada a qualquer momento pela página de Perfil. Resenhas públicas serão mantidas com autoria anonimizada para preservar a coerência do conteúdo da plataforma.

**Retenção:**

Dados pessoais são mantidos enquanto a conta estiver ativa. Após a exclusão, os dados pessoais são removidos em até 30 dias.

## 5. Limitações de responsabilidade

O MyBookList é fornecido "como está", sem garantias de funcionamento ininterrupto, ausência de erros ou adequação a um propósito específico. Como projeto acadêmico em desenvolvimento, o serviço pode apresentar instabilidades, perda de dados ou descontinuação.

O MyBookList não se responsabiliza por:

- Perda de dados decorrente de falhas técnicas, embora façamos esforços razoáveis para preservar as informações
- Conteúdo publicado por outros usuários
- Decisões tomadas pelo usuário com base em informações da plataforma

O usuário pode encerrar sua conta a qualquer momento pela página de Perfil. O MyBookList pode encerrar a conta de um usuário que viole estes termos, mediante notificação prévia quando possível.
